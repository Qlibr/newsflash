Showing inlined sample data — no network request was made to render this. 



      

        

          The default view uses data inlined in the page — the pattern the
          WordPress plugin emits, and the one that needs no proxy at all. "Load
          live feed" switches to real RSS through a public CORS proxy, which is
          fine for a demo and wrong for production: a third party then sees
          every reader. Server-side rendering and self-hosted proxies are both
          covered in the
          README.
